
# 📚 Data Structures Practicals

Welcome to my **Data Structures Practicals** repository!

This repository contains Python programs developed as part of my **Computer Engineering coursework**, covering fundamental Data Structures and Algorithms through practical implementations.

## 💻 How to Run the Programs

### Step 1: Install Python

Make sure Python 3 is installed on your computer.

Check your Python version using:

```bash
python --version
```

### Step 2: Clone the Repository

```bash
git clone https://github.com/josyulaaaditya-pixel/Data-Structure-Practicals.git
```

### Step 3: Open the Project

Open the cloned repository in Visual Studio Code or another Python-compatible IDE.

### Step 4: Run a Practical

Navigate to the required Python file and execute:

```bash
python filename.py
```

Replace `filename.py` with the actual file name.

On some systems, you may need to use `python3` instead.
